Projeto Vite + React com interface em português (Brasil), japonês, inglês e espanhol.

## Executar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

O seletor de idioma aparece no cabeçalho. A escolha é salva no navegador (localStorage). Os textos estão centralizados no objeto `translations` em `src/App.jsx`. A calculadora e o visual original foram preservados.
